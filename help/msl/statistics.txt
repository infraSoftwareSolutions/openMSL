 Object: StatisticsContainer
-------------------
Description of the `StatisticsContainer` class that manages a collection 
of statistical data points, including methods for adding and removing 
items.
It is intended to store key-value pairs where each value has an 
weight representing its frequency or count. This struct supports 
operations like insertion, retrieval based on keys (which could represent 
different variables).
Description: The `StatisticsContainer` class in C++ provides a collection 
of statistical data points and their respective weights.
Purpose: To efficiently manage the storage and querying of variable 
occurrences or frequencies within datasets for analysis. It can store 
multiple items with customizable keys (e.g., variables) along with 
associated frequency counts, allowing efficient tracking and manipulation 
of these statistics without direct memory management outside its member 
functions
Members/Functions: 
- insert(const std::string& key, const T weight): Increments the count 
a given key by one.
- remove(): Removes an item from the container based on equality with 
provided data (the function is not defined here but assumed to be 
implemented internally).
- size() -> int: Returns the number of items currently in the collection. 
This method returns 0 when no elements are present.
- find(const std::string& key): Checks if a specific item exists within 
the container, returning true or false accordingly and does not modify 
anything other than its return value
Description: Searches for an existing entry with matching keys in the 
collection. Returns `true` (or 1) when found; otherwise it returns false.
- clear(): Empties all items from the StatisticsContainer object.
